Lightweight Charts™ is TradingView's open-source library for building fast, interactive financial charts on the web. It renders to HTML5 canvas, ships under 40 KB minzipped, and works in any JavaScript or TypeScript project — no framework required.

## What you can build

Lightweight Charts handles the rendering and interaction layer so you can focus on your data. Typical use cases include:

- **Financial dashboards** — embed candlestick or line charts into trading platforms and analytics tools
- **Portfolio trackers** — visualize asset performance with area and baseline series
- **Market analysis tools** — layer multiple series with overlay price scales, custom crosshairs, and tooltips
- **Custom indicators** — extend the library with the plugin system to add drawing tools, heatmaps, and bespoke renderers

```

```
</CodeGroup>

Or load from a CDN for quick prototyping:

```html
<script src="https://unpkg.com/lightweight-charts/dist/lightweight-charts.standalone.production.js"></script>
```

## Minimal example

```typescript
import { createChart, LineSeries } from 'lightweight-charts';

const chart = createChart(document.getElementById('container'), {
  width: 800,
  height: 400,
});

const lineSeries = chart.addSeries(LineSeries, { color: '#2962ff' });
lineSeries.setData([
  { time: '2024-01-01', value: 100 },
  { time: '2024-01-02', value: 105 },
  { time: '2024-01-03', value: 98 },
  { time: '2024-01-04', value: 112 },
]);

chart.timeScale().fitContent();
```

<Note>
  Lightweight Charts™ is a client-side library. It requires a browser environment with canvas support and does not run server-side (e.g., Node.js).
</Note>
